# Area Riservata & Download — Ora di Lettura (Order Bump)

Progetto indipendente per la pagina di download dell'Order Bump **Ora di Lettura — 24 Testi per Leggere Fino in Fondo**.

## Deliverable
- File PDF incluso in `public/Ora_di_Lettura-orderbump.pdf` (e alias `public/Ora_di_Lettura.pdf` e `public/Ora_di_Lettura-ordernump.pdf`).
- 42 Pagine didattiche in formato A4 con 24 testi inediti graduati su 3 livelli, cronometro di lettura, autovalutazione a stelle, domande di comprensione, soluzioni complete, diario e attestato di completamento.

## Esecuzione in Locale
```bash
npm run dev
```
La pagina si avvia su `http://localhost:3008`.

## Deploy su Vercel
1. Connetti questa cartella o il relativo repository GitHub su Vercel.
2. Vercel rileverà automaticamente il build Vite (`npm run build`).
3. Imposta il dominio o sottodominio desiderato (es. `lettura.tuodominio.com` o `orderbump3.tuodominio.com`).
